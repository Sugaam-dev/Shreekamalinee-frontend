🔐 PHASE 1: Unified Authentication & Role-Based Access Control (RBAC)
Scope: Admin and Customer authentication, token rotation, session hydration on page refresh, and route security.
APIs:
POST /api/v1/auth/login (Admin & Customer password login)
POST /api/v1/auth/register (Customer registration + OTP dispatch)
POST /api/v1/auth/verify-otp (6-digit OTP verification)
POST /api/v1/auth/google-authenticate (Google SSO)
POST /api/v1/auth/forgot-password & POST /api/v1/auth/reset-password
GET /api/v1/auth/me (Session hydration on browser reload)
POST /api/v1/auth/refresh-token (Silent background JWT rotation)
POST /api/v1/auth/logout (Invalidate session)
Frontend Deliverables:
Axios API Client (src/api/client.js) with automatic interceptors.
Role Guards (AdminRoute.jsx for ROLE_ADMIN, ProtectedRoute.jsx for ROLE_CUSTOMER).
All Login, Register, OTP, and Reset Password pages connected.
🏛️ PART 1: ADMIN OPERATIONS
PHASE 2: Categories & Hierarchy Management
Scope: Manage root collections, nested subcategories, suggested attribute specifications, and banner cover uploads.
APIs:
GET /api/v1/catalog/categories
POST /api/v1/admin/categories (Create category/subcategory)
PUT /api/v1/admin/categories/{id} (Update category/slug)
DELETE /api/v1/admin/categories/{id} (Delete category)
POST /api/v1/admin/categories/{id}/images (Upload category banner file)
Frontend Pages: /admin/categories
PHASE 3: Saree Products, Gallery & Specifications
Scope: Publish handcrafted sarees, set original/offer pricing, edit highlights map, add bullet points, and manage high-res photo gallery CDN uploads.
APIs:
POST /api/v1/admin/products (Create saree with highlights and about bullets)
PUT /api/v1/admin/products/{id} (Edit product)
DELETE /api/v1/admin/products/{id} (Delete product)
POST /api/v1/admin/products/{id}/images (Upload high-res photo files)
DELETE /api/v1/admin/products/{id}/images (Remove specific photo)
Frontend Pages: /admin/products, /admin/products/new, /admin/products/edit/:id
PHASE 4: Inventory, Variants & Warehouse Stock Control
Scope: Add color/size variants per saree, monitor low-stock thresholds (stock < 3), and perform live stock adjustments.
APIs:
POST /api/v1/admin/products/{id}/variants (Add variant: size, color, stock, SKU)
PUT /api/v1/admin/variants/{variantId}/stock?stock={n} (Live stock counter update)
DELETE /api/v1/admin/variants/{variantId} (Delete variant)
Frontend Pages: /admin/inventory
PHASE 5: Orders Audit, Manual UPI Verification & Courier Tracking
Scope: Full orders pipeline audit, inspection of customer UTR payment slips, 1-click Approve/Reject, and courier tracking updates.
APIs:
GET /api/v1/admin/orders (List all customer orders across all status tabs)
GET /api/v1/admin/orders/{orderId} (Single order itemized audit)
POST /api/v1/admin/orders/{orderId}/approve (Approve manual payment → mark PAID)
POST /api/v1/admin/orders/{orderId}/reject (Reject payment → auto-restock inventory)
GET /api/v1/admin/orders/{orderId}/receipt (Download/view receipt proof)
PUT /api/v1/admin/orders/{orderId}/status (Update status + courier name, AWB tracking, delivery date)
Frontend Pages: /admin/orders, /admin/dashboard
PHASE 6: Marketing Coupons & Testimonials Moderation
Scope: Multi-scope discount coupon engine (percentage/flat, min spend, categories/products/VIP emails scope) and customer review moderation.
APIs:
POST /api/v1/admin/coupons & GET /api/v1/admin/coupons & DELETE /api/v1/admin/coupons/{id}
POST /api/v1/admin/products/{id}/reviews (Add curated offline VIP review)
DELETE /api/v1/admin/reviews/{reviewId} (Delete spam/inappropriate review)
Frontend Pages: /admin/coupons, /admin/reviews
PHASE 7: Customer CRM & Store Bank/QR Settings
Scope: View customer user directory, search patrons, block/activate accounts, configure bank accounts, and upload the store UPI QR code.
APIs:
GET /api/v1/admin/users?query={search}
PATCH /api/v1/admin/users/{userId}/status?enabled={bool} (Block/Activate)
GET /api/v1/orders/bank-details & PUT /api/v1/admin/orders/bank-details
POST /api/v1/admin/orders/bank-details/qr-code (Upload UPI QR file)
Frontend Pages: /admin/customers, /admin/settings

PHASE 8: Public Catalog, 7-Level Multi-Filters & PDP
Scope: Navbar/hero category browsing, Flipkart-style multi-filter sidebar (Category, Price, Brand, Season, Rating, Discount, Availability), and Product Details Page (PDP).
APIs:
GET /api/v1/catalog/categories/main
GET /api/v1/catalog/categories/subcategories
GET /api/v1/catalog/products (Filtered by all 7 parameters)
GET /api/v1/catalog/products/{id} (PDP with highlights & variants)
Frontend Pages: /, /shop, /product/:id
PHASE 9: Customer Reviews & Ratings Submission
Scope: Display verified buyer reviews and allow logged-in customers to write star ratings and reviews.
APIs:
GET /api/v1/catalog/products/{id}/reviews
POST /api/v1/catalog/products/{id}/reviews (Submit customer review)
DELETE /api/v1/catalog/products/{id}/reviews/{reviewId} (Delete own review)
Frontend Pages: /product/:id (Reviews section & Write Review modal)
PHASE 10: Shopping Cart & Bookmarks (Wishlist)
Scope: Synchronize user cart items with the database, handle quantity changes in the cart drawer, and manage wishlist bookmarks.
APIs:
GET /api/v1/cart & POST /api/v1/cart/items
PUT /api/v1/cart/items/{itemId} & DELETE /api/v1/cart/items/{itemId}
DELETE /api/v1/cart (Clear cart)
GET /api/v1/wishlist & POST/DELETE /api/v1/wishlist/{productId}
Frontend Pages: Cart Drawer, /cart, /account/wishlist
PHASE 11: Delivery Addresses & Checkout Gateway
Scope: Saved delivery address selection/creation, promo coupon validation, order placement, Razorpay payment popup, and Manual UPI receipt upload with UTR.
APIs:
GET/POST/PUT/DELETE /api/v1/addresses
GET /api/v1/orders/coupons/validate?code={code}
GET /api/v1/orders/bank-details (Fetch QR code & bank info)
POST /api/v1/orders (Place order)
POST /api/v1/orders/{orderId}/manual (Upload UTR & payment slip)
POST /api/v1/orders/{orderId}/razorpay & POST /api/v1/orders/razorpay/verify
Frontend Pages: /checkout, /payment, /checkout/success
PHASE 12: Customer Account, Profile & Live Order Tracking
Scope: Customer profile settings, full past order history, order invoice printing, and live courier tracking links.
APIs:
GET /api/v1/users/me & PATCH /api/v1/users/me (Profile management)
GET /api/v1/orders (List user orders)
GET /api/v1/orders/{orderId} (Single order invoice details)
Frontend Pages: /account/profile, /account/orders, /account/orders/:id

Recommended Production Tech Stack
Layer	Technology	Primary Role in Shree Kamalinee
Core UI & Build	React 19 + Vite	High-performance SPA with instant HMR and lightweight bundle sizes.
Styling & Motion	Tailwind CSS v4 + Lucide React	Design system styling, responsive layouts, luxury typography & icons.
Client State	Zustand	Instant, synchronous UI state: Cart Drawer open/close, active client filters, local bag items, and UI alerts.
Server State & Cache	TanStack Query (React Query v5)	Asynchronous server cache: Automatic deduplication, background caching of catalog/categories, mutation hooks (useMutation), and instant cache invalidation (queryClient.invalidateQueries).
HTTP Client	Axios	Configured client.js with baseURL: http://localhost:8081, withCredentials: true, and global interceptors for automatic 401 token refresh.
Auth Security	HttpOnly + Secure Cookies	Maximum security against XSS attacks. Access and refresh tokens are managed in browser cookie jars rather than insecure localStorage.
Form Handling	React Hook Form	Zero-re-render high-performance form state for Login, Product Creation, Address Book, and Checkout.
Schema Validation	Zod	Validates payloads against Spring Boot DTO schemas (e.g. SKU patterns, price bounds, phone numbers, pincodes).
Form-Schema Bridge	@hookform/resolvers (Required companion)	The standard connector allowing React Hook Form to use Zod schemas (zodResolver(schema)).
